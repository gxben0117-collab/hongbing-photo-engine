# 光影系統規範

## 目的

把風格範例中可跨主題重用的光影技法整理成小型共用目錄，再由各工具頁決定哪些技法適合自己的服裝、場景與作品語氣。光影系統不取代頁面專屬的 `lightingData`，也不修改身份鎖定、臉部幾何或真人骨架核心。

## 共用資料契約

`assets/lighting-system.js` 的每筆技法包含：

- `label`：介面顯示名稱
- `family`：`architectural`、`natural` 或 `mixed-ambient`
- `type`：投影、濾光、剪影或雙光源
- `direction`：主光方向
- `quality`：光線硬度
- `contrast`：明暗對比
- `temperature`：色溫關係
- `prompt`：可直接組入生成咒語的精簡英文片段

生成器以頁面資料優先，找不到頁面資料時才使用共用目錄的 `resolve()`。既有選項的輸出因此維持原樣。

## 第一階段技法

1. 百葉窗格柵光影
2. 建築硬光矩形塊影
3. 枝葉斑駁漸層光影
4. 自身剪影疊影牆
5. 冷暖雙色溫對比光

## 分類邊界

- 雜誌、現代寫真、Luxury Lifestyle、旅拍可使用建築硬影、窗影、斑駁光與冷暖環境光。
- 中式古典與日本和服使用時，必須改由本頁的文化場景、服裝與姿勢承接，不加入其他文化服飾語彙。
- 婚紗優先使用斑駁光、矩形窗影與柔和環境逆光；剪影必須保持臉部可辨識。
- 幻想廣告保留五種技法作為試點，但仍由幻想頁的場景與材質決定最終語氣。
- 極限運動的高速凝結、雪霧、浪花與水面強反光屬運動專屬系統，不混入本目錄。

## 不得導入

- 來源人物身份、固定外貌、品牌、浮水印或可讀文字
- 完整長篇來源 Prompt
- 深 V、透明內衣感或泳裝級暴露服裝
- 固定身材數字或與主題無關的妝容、髮色、地域外貌
- 把整個 `Photography Core`、`Pose Core` 或 `Scene Core` 搬入共用核心

## 相容性原則

光影選項應保持人物、服裝、背景使用同一方向、色溫與曝光。不得單獨替臉部補光、漂白或套用脫離場景的美顏光。新增技法與模板必須通過靜態語法、模板引用、UI 流程、Prompt 預覽與 100 次隨機回歸檢查。
