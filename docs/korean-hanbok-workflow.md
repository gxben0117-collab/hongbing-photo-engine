# 韓國韓服美學流程

## 定位

`korean-hanbok.html` 是獨立的韓國韓服美學咒語產生器。頁面只負責韓服、韓式材質、
紋樣、配件、姿勢、光影與場景；不引用日本和服、中式古典、仙俠或科技幻想的正向服裝
資料。

## 服裝主題

03 服裝主題為單選，共 15 套，分成三組：

- 傳統朝鮮韓服：傳統圓衫齊胸裙、早期朝鮮長襖、晚期朝鮮短襖、文人粉彩韓服、冬季毛邊韓服
- 宮廷／婚禮韓服：宮廷唐衣、宮廷圓衫、婚禮華衣、綠色婚禮圓衫、金箔宮廷韓服、宮廷舞蹈韓服
- 新式韓服：日常新式韓服、韓服寫真高訂、舞台偶像韓服、韓服精品高訂

## 生成順序

成品語氣 → 構圖取景 → 韓服主題 → 韓國材質／紋樣（最多 2 個） → 韓服飾品（單選）
→ 服裝改造核心 → 身形輪廓 → 人物姿勢 → 自訂要求 → 光影方式 → 色彩系統 →
背景場景 → 拍攝角度 → 圖片比例 → 生成咒語。

自訂服裝放在 03、材質／紋樣放在 04A、自訂姿勢放在 07、指定配色放在 09B、自訂背景放在 10；
08 自訂要求只保留畫面強度與其他要求。背景另提供無背景純白色。

## 核心規則

- `assets/core-prompt.js` 以 `page.koreanHanbok` 提供韓國專用頁面核心，身份與臉部幾何
  基準仍沿用共用 v4.3 保護核心。
- 正向生成使用韓服、저고리／jeogori、치마／chima 等韓國服飾語彙，並保留所選韓服的
  上衣、裙身、袖型、繫帶與整體輪廓。
- 負面限制排除日本和服、中式漢服、旗袍、仙俠、魔法、科技幻想與武士風格混用。
- 「原服裝一致」不產生多餘英文片段；材質最多 2 個，頁面不提供額外留白方向，隨機與模板都走同一份資料池。
- 服裝改造核心含 Layer 0／3／6／9／隨機 Layer；Layer 只控制隨機套用的改造部位數，
  保留手動選擇且不輸出 Prompt。模板依三區實際啟用數回填對應 Layer。
- 12 組一鍵模板集中於 `themeTemplates`，每個模板完整設定風格、構圖、服裝、材質、
  配件、身形、姿勢、攝影與比例。
