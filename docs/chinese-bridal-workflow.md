# 中式婚嫁藝術寫真流程

中式婚嫁頁是單人新娘的東方婚嫁精品攝影工具，專注龍鳳褂、秀禾服、鳳冠霞帔、明制／宋制婚服與新中式婚嫁高訂。它與 `bridal-editorial.html` 分開：西式頁保留婚紗、頭紗、教堂與海岸婚紗語彙，本頁不把西式婚紗當成正向主體。

## 控制順序

一鍵模板 → 成品用途 → 構圖取景 → 婚服形制 → 中式婚嫁工藝與材質 → 服裝改造核心 → 婚嫁儀式層與配件 → 身形 → 中式婚嫁儀態與姿勢 → 妝髮與膚質 → 光影與色彩 → 背景 → 自訂要求 → 鏡頭 → 比例 → 生成。

## 服裝資料邊界

03 決定婚服形制，04 決定織金、刺繡、緙絲、雲肩與中式紋樣，05 只控制胸口、腰側與肩部局部結構，06 補充鳳冠、霞帔、披帛、團扇與其他婚嫁配件。Layer 0／3／6／9／隨機 Layer 只影響隨機套用；手動選取的部位不會被覆蓋，Layer 本身不輸出到 Prompt。

自訂服裝放在 03，自訂工藝放在 04，自訂姿勢放在 08，自訂配色放在 10，自訂背景放在 11。選擇「原服裝一致」或「無」時，不追加該部位的英文片段。

## 核心與生成邊界

- 沿用 `assets/core-prompt.js` 的身份、臉部幾何、真人骨架、鏡頭、光線一致與輸出保護核心，不建立平行鎖臉核心。
- 中式婚嫁的形制、工藝、配件、儀態、場景與色彩留在本頁資料；不回灌中式古典、仙俠或其他文化服飾頁。
- 只生成單一成年女性人物，不由模板或隨機套用主動加入新郎、伴郎、伴娘或其他第二人物。
- 囍字、紅金、喜堂、古宅與婚嫁儀式只能由本頁控制項與模板輸出；不把西式教堂長頭紗、白紗魚尾或 85mm 婚紗專屬資料混入本頁。
- 構圖、鏡頭、比例、身形與 Layer 沿用正式真人人像頁的共用契約；主題專屬差異只追加在本頁資料。

## 驗收重點

- 所有 12 組模板都完整回填婚服、工藝、服裝改造、儀式層、身形、姿勢、妝髮、光影、背景、鏡頭與比例。
- `chinese-bridal.html` 納入首頁、主題 registry、靜態檢查、UI flow、DOM 順序、模板引用、主題分類與 100 次隨機回歸。
- 生成後不得出現 `undefined`、`NaN`、`[object Object]`；自訂要求採純文字輸出，並保留鎖臉衝突提示。
