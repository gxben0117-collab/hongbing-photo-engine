# 四頁精品質感提升＋中式青春古風擴充

版本：v4.40
範圍：`chinese-classical.html`、`japanese-kimono.html`、`kpop-idol.html`、`bridal-editorial.html`

## 1. 目標

提升四個正式工具頁的成品質感，讓輸出從廉價電商、租借服裝或制式商品目錄，轉向高預算時尚編輯、精品廣告與典藏肖像方向。同時在中式古典頁加入青春、戀愛感、靈動與自然活力，但不改變原有頁面架構、身份鎖定、服裝分類與生成流程。

## 2. 共用精品成像核心

新增 `assets/editorial-finish.js`，以 `window.HB_EDITORIAL_FINISH` 提供：

- `base`：高預算編輯製作、單一主體視覺層級、方向性主光、填光與輪廓分離、材質重量、縫線、工藝與高級光學細節。
- `themes.chineseClassical`：真實漢服布料、緙絲／錦緞／刺繡、漆黑、黛青、玉色與古金的節制使用。
- `themes.japaneseKimono`：和服領襟、袖形、帶芯厚度、西陣織與漆器反光的可信結構，避免觀光租借服質感。
- `themes.kpopIdol`：真實舞台高訂剪裁、縫線、五金與受控反光；舞台效果只能服務人物，不喧賓奪主。
- `themes.bridalEditorial`：蕾絲網、緞面重量、胸衣支撐、珠工固定方式與頭紗層次，避免婚紗展示間堆飾。
- `negative`：排除扁平電商光、租借服、塑膠裝飾、印刷感刺繡、假布料高光、過度飽和與過度堆景。

四頁只載入這個共用模組；`assets/core-prompt.js` 僅更新版本號，不修改身份、臉部幾何或真人骨架文字。精品核心放在構圖與身份／骨架之後、服裝與材質之前；精品負面限制放在頁面既有負面限制之後。

## 3. 中式青春古風擴充

### 3.1 新增畫面語氣

在既有風格單選中加入：

1. `青春古風寫真`：成人清新、明亮、自然活力。
2. `戀愛感古風寫真`：初戀氛圍、溫柔眼神、自然情緒敘事。
3. `靈動微性感寫真`：優雅女性魅力、自然肩頸與姿態，不使用直白或幼態描述。

不得加入年齡數字、`young girl`、兒童化比例或 baby-face 指令；仍以參考人物的身份、年齡印象與臉部幾何為最高優先。

### 3.2 新增動態姿勢

加入五組可單選姿勢：

- 回眸輕笑
- 撥髮迎風
- 古街快步
- 輕快轉身
- 抬眼自然笑

每組姿勢需保留自然手指、平衡重心、頭頸肩脊椎連續性，並能展示衣袖、飄帶或裙擺。姿勢資料使用現有 `poseData` 與 `pose=auto` 機制，不新增另一套姿態核心。

### 3.3 新增光影與配色路線

加入三組互相搭配的方向：

- 春日高調自然光＋春日粉彩／桃粉玉色
- 古街漫射日光＋淡雅古典配色
- 飄帶髮絲逆光＋玉白墨色或低飽和古典配色

另提供精品主視覺需要的漆黑鎏金、黛青玉白光影與配色選項。光影與配色仍由既有 `lighting`、`color` 控制，不新增額外 UI 層。

### 3.4 五組青春古風一鍵模板

模板集中定義於 `themeTemplates`，每組完整回填服裝、材質、飾品、畫面語氣、構圖、身形、姿勢、鏡頭、光影、背景、配色、比例與畫面強度：

- 春日花簪清新人像
- 古街明亮回眸
- 花市戀愛感寫真
- 藍紫古風街拍
- 盛唐花園靈動特寫

## 4. 四頁精品模板

每頁新增「精品主視覺」隨機按鈕，從兩組完整模板中抽取；每組模板都必須以既有 `applyThemeTemplate` 連動，不得只改畫面標籤。

| 頁面 | 模板一 | 模板二 |
|---|---|---|
| 中式古典 | 漆黑鎏金新中式封面 | 黛青玉白典藏肖像 |
| 日本和服 | 漆黑金箔和服高訂 | 和紙墨白典藏肖像 |
| 韓系偶像 | 黑金回歸精品主視覺 | 銀黑美妝大使 |
| 婚紗藝術寫真 | 黑金香檳婚紗高訂 | 珍珠灰白典藏婚紗 |

模板內容須維持主題文化與既有頁面專屬核心，不把中式、和服、韓系或婚紗正向語彙互相混用。

## 5. 生成與身份規則

- 不改變任何既有身份鎖定、臉部幾何、真人骨架、最終身份優先與光線一致核心。
- 精品模組只描述製作質感、材質、光影、層次與構圖秩序，不描述重建臉部或替換人物。
- 生成順序保持：身份／骨架 → 構圖 → 精品成像 → 服裝／材質 → 姿勢／鏡頭 → 光影／背景／比例 → 負面限制。
- 自訂內容仍遵守原頁面規則；空白自訂欄位不得輸出 `undefined`、`null` 或空標籤。
- 正向 Prompt 不新增仙俠、科技幻想、跨文化服飾或角色身份詞；精品負面限制只排除廉價成像失敗模式。

## 6. 驗收

必須通過：

```powershell
node scripts\check-static.mjs
node scripts\check-ui-flows.mjs
node scripts\validate-preset-refs.mjs
node scripts\audit-100x.mjs 100
node scripts\build-prompt-preview.mjs --out output\prompt-preview-v4.40-final
git diff --check
```

稽核結果需確認：19 頁共 1900 組隨機輸出無 `undefined`、`NaN`、`null`、身份核心遺失或相鄰重複行；四個目標頁的生成輸出均包含精品成像核心；中式頁的 25 組模板與新增青春選項全部可被 UI、隨機池與生成函式引用。
