# 風格範例不採用要素記錄（2026-08-22）

本檔只記錄本輪圖片盤點中「看過但不直接寫入正式工具」的要素，避免之後重新分析時誤把研究素材當成正式規格。

## 不採用原因

| 要素 | 原因 | 可保留的安全抽象 |
| --- | --- | --- |
| 車展泳裝、內衣式近距離展示 | 服裝尺度與畫面焦點過度集中身體，不適合共用核心 | 可保留「展覽場景、硬質反光、產品展示光」作為研究語言 |
| 運動服、球棒與品牌字樣 | 偏離目前工具主題，且含可辨識文字／品牌 | 可保留「乾淨白色棚拍、動態道具構圖」但不做正式模板 |
| 辦公室絲襪與高跟鞋組合 | 容易把商業寫真導向 fetish 語氣 | 可保留「辦公室生活方式、桌邊坐姿、自然窗光」 |
| 居家短裝、赤腳沙發姿勢 | 與 Luxury Lifestyle 接近，但服裝裸露比例及身體展示過重 | 只採用公寓、沙發側坐、窗光與生活方式構圖 |
| 品牌招牌、服裝字樣、作品名 | 會污染主題資料，並可能造成模型生成錯字或仿冒品牌 | 改寫為「無文字、無 Logo、乾淨背景」 |
| 固定酒紅髮、固定人物年齡與原始身份描述 | 可能覆寫參考照人物，稀釋鎖臉核心 | 只保留服裝、姿勢、場景、鏡頭和色彩語言 |

## 核心保護

本輪不採用清單不會加入 `assets/core-prompt.js`，也不會產生平行身份系統。正式模板只提供主題控制項；身份、臉部幾何、真人骨架、頭頸肩脊椎連續性與全域負面限制仍由既有核心負責。
