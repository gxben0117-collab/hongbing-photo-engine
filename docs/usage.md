# 使用方式

1. 開啟 `index.html`，從旅拍、雜誌棚拍、公仔、幻想廣告、中式古典美學、日本和服美學、韓國韓服美學、仙俠、動漫人物、
   花仙子、異世界、店家廣告、花漾甜美、晚宴名媛、韓系偶像、戰鬥學院、古代女神或編輯視覺設計
   選擇工具。
2. 依該頁的決策順序選擇內容；共同頁通常是版型／構圖、服裝、材質、服裝改造、身形、
   姿勢、自訂、光影、背景、鏡頭與比例，特殊頁會依工作目的調整順序。
3. 需要快速起稿時使用「一鍵套用」或「隨機套用」；旅拍、雜誌、幻想廣告套用後會立即
   生成並顯示結果。
4. 手動改動已生成結果後，先重新點選「生成咒語」；輸出過期時「複製咒語」會暫停，避免
   複製到與畫面選項不一致的舊內容。
5. 使用「複製咒語」貼到生圖模型。編輯視覺設計頁則需把已生成照片一併提供給 ChatGPT，
   讓它只做版型與後製設計，不重新生成人物。

## 編輯視覺設計

編輯視覺設計是 Stage 2 後製工具，不負責重新設計人物。00 一鍵模板分成六類，共 31 組：
時尚編輯 6、美業廣告 4、動漫電玩 4、電影海報 7、寫真書 5、旅遊設計 5。選擇分類後，
按模板即可一次套用版型、人物版位、字體、文案語氣、主圖形、輔助標記、色彩、影像處理、
印刷質感、留白、語言與圖片比例；自訂文字會保留，不會被模板清空。

生成時必須把原始照片和咒語一起提供。咒語會鎖定人物、臉部、髮型、妝容、服裝、身形、姿勢、
光線、鏡頭與背景，只允許增加標題、資訊欄、圖形、色彩與印刷／版面效果；未提供的產品、
成分、醫療宣稱、目的地、座標、署名與日期不會由工具自行補造。

## 資料層原則

- 介面顯示層維持繁體中文
- 邏輯 key 使用英文
- 最終輸出咒語使用英文
- 需要追查時再看中文對照或文件

## 多選與預設

- 任何同時提供胸口、腰側、肩部的服裝改造核心，都包含 Layer 0／3／6／9／隨機 Layer。
  Layer 只控制「隨機套用」要補足約 0／1／2／3 個改造部位；手動已選部位會保留，Layer 不會
  進入生成 Prompt。手動操作仍可自由選擇三區，不受 Layer 數量限制。
- 雜誌妝容與珠寶配飾各最多 2 個；「原圖一致」與「無」是覆蓋型選項。
- 中式古典美學的 04A 傳統材質與紋樣最多 2 個，04B 中式飾品單選；09 分開控制光影與色彩，
  10 只控制背景場景，並提供「無背景純白色」與下方自訂背景。服裝主題為漢風、盛唐、宋韻、
  唯美古風四組十九套單選方向；自訂服裝放在 03、材質／紋樣放在 04A、姿勢放在 07、配色放在 09B，
  三頁的 08 自訂要求只保留畫面強度與其他要求。
  江南水墨只控制背景與氣氛。
- 日本和服美學與韓國韓服美學是兩個完全獨立的國別頁；各頁的服裝主題、材質／紋樣、
  飾品、姿勢、光影、色彩與背景資料不互相共用，生成核心也會排除其他國別服飾語彙。
- preset 會重設它負責的欄位，未指定的欄位沿用頁面設計的安全預設。
- 若看到輸出區的 stale 提示，代表畫面選項已變更，重新生成後才是目前版本。
