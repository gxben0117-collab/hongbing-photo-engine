## 分類與實作原則

1. 一張圖片只有一個 primary owner；相似畫面可留作候選，但不得在多個正式頁重複建立同名模板。
2. 場景、服裝、姿勢、光影與色彩只進入所屬頁面資料，不把來源人物外貌、品牌、水印或固定身材寫入共用核心。
3. 一鍵模板必須回填完整作品概念，至少包含主題、場景、服裝、姿勢、光影、構圖、鏡頭與比例。
4. 新增資料必須同時通過靜態語法、模板引用、UI flow 與 Prompt 預覽檢查。
