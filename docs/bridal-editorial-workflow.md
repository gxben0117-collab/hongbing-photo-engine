# 西式婚紗藝術寫真流程

西式婚紗藝術寫真頁是單人新娘的精品婚紗攝影工具，定位為婚紗棚拍、婚紗廣告與婚紗雜誌寫真，不是婚禮流程紀錄工具，也不承擔中式婚服形制。

## 控制順序

一鍵模板 → 成品用途 → 構圖取景 → 婚紗輪廓 → 婚紗工藝與材質 → 服裝改造核心 → 頭紗與配件 → 身形 → 姿勢 → 妝髮膚質 → 光影配色 → 背景 → 自訂要求 → 鏡頭 → 比例 → 生成。

## 身份與頭紗

頁面沿用 `assets/core-prompt.js` 的身份、臉部幾何、真人骨架與光線核心。頭紗保護只在選擇頭紗時追加，透明頭紗可以位於臉後或臉側；覆面頭紗屬高風險選項，不進一般隨機池。

## 服裝邏輯

03 決定整件婚紗外型，04 決定布料與工藝，05 只決定胸口、腰側與肩部的局部結構。Layer 0／3／6／9／隨機 Layer 只影響隨機套用，不輸出到 Prompt；手動指定的部位不會被隨機覆蓋。

## 生成邊界

- 只生成單一成年女性人物，不主動加入新郎、伴郎、伴娘或第二位人物。
- 頭紗、裙襬、花束與配件必須依選項條件輸出，不選就不加入。
- 構圖留白只代表乾淨排版空間，不生成標題、引言、Logo 或隨機文字。
- 婚紗風格只影響服裝、配件、姿勢、光線、背景與攝影語氣，不改寫身份與五官。

## 參考模板
